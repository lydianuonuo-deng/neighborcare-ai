# V0.2 报修可靠性优化计划

目标：改善已确定 PRD 中的草稿、提交和查询流程；沿用现有页面、接口及权限规则，不变更数据库。

已知证据：NewReport 直接调用 localStorage，权限异常会中断保存与提交；API 请求在 fetch 返回响应头后即撤销计时，正文读取没有超时；居民列表没有手动刷新入口。

方案：浏览器缓存读写采用容错包装，失败时仅保留本页内存并明确提示刷新风险；请求计时覆盖完整响应正文，无效成功响应显示可理解的错误；居民列表增加刷新按钮，更新期间保留已显示记录并禁用重复刷新，失败保留旧数据。

不采用重新设计数据库或自动轮询：本轮问题均可在现有页面修复，手动刷新也避免增加后台请求。
