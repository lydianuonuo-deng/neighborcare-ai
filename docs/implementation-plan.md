# 邻里报修 AI 开发计划

**目标：** 将 V1.3 PRD 实现为可运行、可测试的单场地原型。

**架构：** React 页面与 Express 服务同源，SQLite 持久保存会话、草稿、工单、事件和任务。服务端原子校验权限、版本和幂等键；AI 只有读取输入并建议结构化内容的能力。

**技术：** TypeScript、React、Vite、Express、Node SQLite、sharp、node:test、Playwright。

## 文件责任

| 路径 | 责任 |
|---|---|
| `shared/types.ts` | 页面与接口的数据契约 |
| `server/config.ts` | 环境配置与启动校验 |
| `server/db`、`server/auth` | 数据迁移、事务、会话鉴权 |
| `server/drafts`、`server/tickets` | 输入版本、提问预算、工单状态、回执及重开 |
| `server/uploads`、`server/tasks` | 私有附件与持久任务 |
| `server/ai` | 真实兼容接口、模型结果验证、受控失败 |
| `client` | 居民和工作人员操作界面 |
| `tests` | 真实数据库/API测试及浏览器闭环 |

## 已确定边界

F14 自动合并、跨场地、支付、自动派单、维修质量和安全判断均不开发。F09语音和F10统计非核心，先保证完整主流程。没有密钥时显示模型不可用并保留人工操作，不把规则或测试替身当作模型成功。示范数据属于独立场地；不创建定时任务，也不自动报名或部署。
