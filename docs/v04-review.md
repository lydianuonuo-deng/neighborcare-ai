# V0.4 独立审查及修复记录

范围：账号持久化、角色/场地控制、独立页面、会话、草稿身份隔离。基线为V0.3源码包，当前工作区没有Git仓库；审查由独立代理只读进行，复现仅使用临时库/浏览器模拟。

| 级别 | 已复现问题 | 修复 | 回归 |
|---|---|---|---|
| P1 | 较慢的旧bootstrap响应可覆盖新身份；A本地草稿可能通过B会话重新创建 | 初始化请求序号；创建草稿绑定期望账号，后端不一致拒绝 | 桌面/窄屏均实际延迟A响应，在B登录后释放；B表单仍为空。接口验证旧期望ID403 |
| P2 | 合法32位工作人员用户名追加2生成33位第二账号，启动异常；部分种子配置不符登录约束 | 第二用户名截断并避开首账号/管理员冲突；统一配置用户名及密码上限 | 32位首账号且管理员与默认第二账号冲突仍创建3个独立合法账号；无效输入提前拒绝 |
| P2 | 注册自动切换身份，限流若按当前身份计数会生成新桶 | 注册使用稳定IP键 | 两个已登录身份轮换提交，仍共用30次额度，超出429 |

浏览器回归还暴露同IP连续成功登录耗尽10次请求额度。登录采用共享全局IP请求预算及每账号失败预算，成功请求退还失败计数；12次连续成功登录及10次失败封锁回归均通过。两个登录接口共享计数，防止切换入口绕过。

全量测试另发现Node环境调用页面API时无window导致401被错误改写为网络异常。事件通知增加浏览器环境判断，原友好错误测试通过。窄屏视觉检查修正品牌文字被既有侧栏样式隐藏、文字链接垂直对齐问题。

审查未发现额外角色、场地、负责人或停用/改密会话版本绕过；这属于本轮检查范围内的结论，并非外部渗透测试结论。证据见[当前验收](verification.md)。
