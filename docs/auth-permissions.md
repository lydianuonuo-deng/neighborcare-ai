# 账号与权限说明（V0.4）

角色权限指按登录身份决定可访问哪些页面、可执行哪些动作；后端逐请求验证，前端导航用于提示。

| 操作 | 未登录 | 居民 | 工作人员 | 管理员 |
|---|---|---|---|---|
| 登录页、公开注册 | 可访问 | 显示当前账号 | 显示当前账号 | 显示当前账号 |
| 创建新报修、补充/确认/重开自己的报修 | 不可 | 可（本人、状态有效） | 不可 | 不可 |
| 查看居民工单 | 不可 | 本账号 | 本场地 | 本场地 |
| 认领、进展、回执 | 不可 | 不可 | 本场地，遵守负责人/状态校验 | 同工作人员规则 |
| 看板、统计、汇总导出 | 不可 | 不可 | 本场地 | 本场地 |
| 账号列表、开通工作人员、停用/恢复 | 不可 | 不可 | 不可 | 本场地；不能停用自己/管理员 |
| 修改本人密码/退出 | 不可 | 可 | 可 | 可 |

公开注册仅创建居民；额外提交角色参数会被拒绝。管理员管理账号的接口不会将新账号自动登录到管理员浏览器。居民账号只能由本人注册，管理员不能在界面中把居民提升为工作人员或管理员。

## 页面与会话

- `/login` 与 `/register` 是单独页面，认证前不加载工单数据。登录回跳仅接受本站该身份可以访问的页面。
- `/account` 显示当前身份和密码表单；必须核对旧密码。改密递增会话版本并撤销全部旧令牌，回到登录页。
- `/staff/users` 仅管理员可访问；停用保留工单归属及历史，停止访问并撤销旧会话。恢复后仍需重新登录。
- 登录清除当前浏览器其他角色Cookie；同一浏览器使用一个身份。另一个设备可以独立登录同账号。
- 居民登录最长30天、工作人员/管理员8小时，退出撤销当前浏览器登录。登录失效的私密请求会触发页面重新验证。
- 前端通过同源标签通信同步身份变化，不广播账号、姓名、密码或令牌。旧初始化响应按请求顺序丢弃；创建草稿额外携带期望账号，切换身份后拒绝旧页面创建。

## 旧游客记录

原游客Cookie仍有效时，注册新居民账号沿用该身份ID，因此旧草稿、工单及附件的归属不改变。旧Cookie本身不能继续访问新的私密接口。前端在认证前将旧缓存绑定到明确的游客身份，注册后同ID继续恢复；其他已有账号不会自动合并游客记录。无原会话时无法仅凭链接或编号证明归属。

新草稿及待提交恢复键使用账号ID区分。浏览器禁用存储时仍允许手动保存/提交，但本地文本副本可能仅在当前页面有效；服务端已保存的草稿和记录仍受账号权限保护。

## 存储和配置

账号保存独立随机盐、scrypt摘要和会话版本；不在接口中返回密码材料。会话令牌仅放在HttpOnly Cookie，数据库保存令牌摘要；生产Cookie同时设置Secure和SameSite=Strict。

环境变量 `STAFF_USERNAME/PASSWORD`、`ADMIN_USERNAME/PASSWORD` 仅首次创建账号，后续启动不覆盖已有密码或停用状态。需要更改密码时，在账号与安全页面操作。演示重置命令会删除演示账号，重启重新按环境配置创建；必须先备份并停止服务。

公开注册每IP每分钟30次；统一及兼容工作人员登录共享每IP每分钟60次请求，以及每IP+场地+账号每分钟10次失败额度，成功登录不消耗失败额度。密码派生最多2个并发，等待队列有界。当前单进程部署，限流状态在进程内；正式多进程部署需共享限流存储。

没有短信、邮箱验证及自助找回密码服务；不把未验证的手机号或邮箱当作账号归属凭据。

密码实现依据：[Node.js Crypto](https://nodejs.org/docs/latest-v22.x/api/crypto.html#cryptoscryptpassword-salt-keylen-options-callback)、[OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。采用随机16字节盐、scrypt N=16384/r=8/p=5/maxmem=64MiB，并通过本地实际派生与登录测试验证。
